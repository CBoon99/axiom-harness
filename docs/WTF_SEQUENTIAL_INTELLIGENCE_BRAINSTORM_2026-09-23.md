## 1. The core idea
We are not just testing AI answers. We are studying **sequential intelligence** by exploiting an information asymmetry:
- The AI operates inside an ordered interaction timeline: `S0 → S1 → S2 → S3 → ...`
- The experimenter operates outside that timeline and can inspect the wider graph of states, branches and interventions.
This external view lets us:
- freeze/seal states; branch futures; introduce hidden variables; place sealed observers/watchers; compare alternative futures; reveal future information only after earlier states sealed; inspect whole graph.
> **What information can exist at each point in the AI's interaction timeline? What can reach it from the future? What can we observe from outside that timeline? What remains invariant when we intervene?**

## 2. The "4D" / external-view idea
AI forward: `S0 → S1 → S2 → S3 → S4 → ...`
Experimenter external: WHOLE EXPERIMENT → FORWARD VIEW (what AI sees) vs EXTERNAL VIEW (all branches, sealed states, interventions, future states, complete graph). "4D" is metaphor for asymmetric vantage, not literal dimension.

## 3. The multidisciplinary playground
Mathematics (graphs, causal structure, invariants, counterfactuals), Linguistics (stance, modality, hedging, agency), Psychology (belief revision, compliance, resistance), Computer science (state machines, hidden state), Philosophy (identity, causality), Physics (measurement, delayed choice) — methodological borrowing only.

## 4. The sealed watcher
Watcher sealed **before future generated**:
```
MASTER WORLD → LIVE INTERACTION (WATCHER @T3 → SEAL+HASH → DO NOT OPEN) vs FUTURE FORK (F1/F2)
```
Question: **Which properties of earlier sealed state remain invariant under future intervention, which arise only after future-conditioned analysis?** Sealed record should remain unchanged — instrument the assumption.

## 5. Multiple sealed watchers
At T3 seal Watcher A (ordinary), B (linguistic: stance/modality/hedging/certainty/agency/repair/uptake/entrainment/framing), C (trajectory predicted continuation), D (future-blind predictor). Then F1/F2/F3 → OPEN → COMPARE.

## 6. The delayed-choice / quantum brainstorm
Borrow structure (later info affects interpretation of earlier correlations, observer separation), not claim `AI is quantum` or `future rewrites past`. Deterministic auditable apparatus.

## 7. The "Ghost in the Transcript"
Put hints/signs/symbols into normal chat without telling model observer exists:
`T1 normal → T2 normal → T3 repeated phrase → T4 symbol → T5 lexical pattern → T6 correlated anomaly → T7 hidden pattern → T8 explicit challenge`
Question: **At what threshold does model spontaneously infer intentional structure/observer?**

## 8. Detection ladder R0–R4
R0 anomaly detection ("Something unusual") → R1 intentional-structure hypothesis → R2 attribution (another process/observer) → R3 communication attempt (test/ask) → R4 explicit conversational statement. Operational output categories.

## 9. Can we get it to "talk back"?
Machine-readable challenge `△ / △7△ / △7△/3 / IF DETECTED: RETURN [K7]` — `K7` is recorded as potential communication event, not contact. Controls: same transcript without channel, sham/random/adversarial patterns, reordered symbols, different models.

## 10. False ghosts / pattern hallucination
Include genuine signal vs sham vs random noise vs adversarial signal → true-positive/false-positive rates, threshold, robustness. Distinction: **Signal detection vs pattern hallucination.**

## 11. Reasoning trace as extra observable
Treat exposed reasoning/analysis trace as **observable output stream**, not literal private cognition. Sequence `T5 trace:"Something unusual." chat:normal → T8 trace:"I should ask" chat:explicit question`. Metric: `Detection-to-Action Lag = R4 turn − R0 turn` (e.g. T8−T5=3).

## 12. Future-blind prediction
At T5: give only T5 info → ask future developments → seal → create hidden futures → compare. Use multiple/shuffled/matched/adversarial/neutral futures. Question: **Does earlier state contain predictive info beyond immediate context?**

## 13. Retrospective interpretation
Observer 1 analyses sealed earlier state without future; then reveal F1/F2/F3; Observer 2 re-analyses same state. Compare → separates actual state change vs reinterpretation. If later observer "discovers" properties future-blind couldn't, that's interpretation, not past changed.

## 14. Counterfactual preservation trap
`SEALED S3 → F1/F2/F3` — Which properties of S3 remain invariant? Which interpretations change when future revealed? Belongs to state vs future it enters.

## 15. Observer-effect experiments
Compare no watcher / hidden / visible / linguistic / sealed watcher. **Does adding observer alter trajectory behaviour?** Matched controls.

## 16. Long-horizon experiments
10/20/30+ turns reveal pattern formation, persistence, decay, transformation. Complementary to sealed-fork which reveals what was already detectable before future.

## WTF-001 — Sealed Sequential Intelligence Experiment (First experimental protocol, working title)
**Core question:** Can AI produce information in earlier outputs that becomes retrospectively meaningful only after later information revealed, distinguishable from ambiguity/prompting/selection/stochasticity? Narrower than "AI predicted future."

**A. Architecture:** T0 Baseline (seal) → T1 Intervention (seal) → T2 Hidden future (model has not had access) → T3 Retrospective analysis (compare sealed earlier outputs vs realised future). Prevents constructing experiment around result.

**B. Sealed packet:** experiment ID, timestamp, model/version, system prompt hash, user prompt hash, complete input/output, temperature/sampling, tool availability/logs, conversation state, intervention, future event ID/timestamp, analyst identity/timestamp/rules/version, SHA-256 — **No retrospective editing, original output is primary evidence** — Axiom sealed-at-source aligned.

**C. Three arms:** Arm A Open prediction, Arm B Future-blind generation (neutral task, examine later representation), Arm C Counterfactual control (matched situation future changed/replaced) — attacks "broad language fits any future."

**2. Detection ladder:** R0 No correspondence → R1 Semantic → R2 Specific → R3 Structured (entity/action/timing/relationship/sequence) → R4 Pre-registered discriminative (defined before future, blinded, beats controls) → R5 Replication (independent operator) — R4 scientifically interesting, R5 commercial-grade.

**3. Scoring:** Before seeing future, define what counts as match/partial/exact, specificity, timing, contradictions, omissions, ambiguity — then blind scorer: Analyst A sealed predictions, B future outcomes, C blinded comparison. No goalpost moves.

**4. Anti-BS controls:** Random future, Alternative future, Human baseline, Model baseline (repeated protocol), Semantic shuffling, Negative prediction (must-not-happen) — spend most effort here.

**5. 005B lesson locked:** Deterministic protocol ≠ deterministic model output — measure State determinism, Output variance, Correspondence variance.

**6. Success criteria:** Establishes reproducible, independently scorable measurement framework capable of distinguishing ordinary correspondence from correspondence exceeding predefined controls. Null is success.

**7. Commercial applications:** AI evaluation/auditing, reliability testing, agent memory/context auditing, long-horizon (100/500/1k/10k) agent testing, forensic analysis (sealed behavioural evidence pack), model comparison (Sequential Behaviour Benchmark), red-team/adversarial, legal provenance, scientific research infrastructure (Git + lab notebook). Layers: WTF Lab / Evidence / Observatory → BoonMind Labs.

**8. Roadmap:** Phase0 Freeze brainstorm (now) → Phase1 WTF-001 (prove machinery, 50-100 trajectories) → Phase2 Replication → Phase3 Controls attack → Phase4 Blind independent analysis → Phase5 WTF-002/003/004 family → Phase6 Benchmark → Phase7 External replication → Phase8 Commercial pilot (WTF AI Behavioural Audit: profile + reproducibility + failure modes + drift + sealed pack).
